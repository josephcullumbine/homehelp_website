# Help at Home website

Plain HTML, CSS and JavaScript. No build step: open `index.html` in a browser, or upload this folder to any static host.

## Where things live
| To change… | Edit |
|---|---|
| Business name, phone, email, area, hours, reply time, domain | `assets/js/config.js` |
| Services list, "What we don't do" list, trust and safety items, form delivery | `assets/js/config.js` |
| Colours, fonts, spacing | the `:root` block at the top of `assets/css/styles.css` |
| Logo | replace `assets/img/logo-mark.svg` and `assets/img/favicon.svg` |
| Header, footer and menu | `assets/js/site.js` (shared by every page) |
| Page wording | the page's `.html` file |

Remaining placeholders and open questions are listed in `../TODO.md`.
